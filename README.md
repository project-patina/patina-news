# Patina news

Messages shown on the Patina launcher's home screen. The launcher reads `updates/index.json` from this repository; no token or account is involved.

To add a message, add an entry to `updates/index.json` with Polish and English text, its two Markdown files and an image in `updates/images/`. The three newest entries are shown. Format: `docs/ANNOUNCEMENTS.md` in [project-patina/patina](https://github.com/project-patina/patina).
